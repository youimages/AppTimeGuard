AppTimeGuard

v1.0 · 应用使用时长监控与锁定

下载 APK

5.6 MB · Android 7.0+

功能特性

  • 监控各 App 当日累计使用时长
  • 为每个 App 设置每日使用上限
  • 达到上限自动弹出全屏锁定覆盖
  • 次日 0 点自动重置，恢复使用
  • 开机自启，后台持续守护
  • 无需联网，数据完全本地存储

安装步骤

  • 下载 APK 并安装
  • 打开 App，点击「去授权」
  • 授予「使用情况访问」权限
  • 授予「悬浮窗」权限
  • 返回 App，打开监控开关
  • 点击任意 App 设置每日上限
⚠️ 安全提示： 本 APK 为 debug 签名版本，安装时手机可能提示「未知来源应用」，请在系统设置中允许安装。仅用于自我时间管理。
